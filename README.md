My entry for the make.fun "Worst Superpower" bounty: one line inventing the most useless superpower imaginable.

> I can fly, but only three inches off the ground and only backwards, so my escape from the bank robbery was a slow moonwalk into a wall.

Run `main.ts` with Node to write the line to `/output/entry.txt`. The entrypoint
checks the line against the competition's 140-character limit before writing.
